# 🎬 Mythos - Biblioteca de Películas

Mythos es una interfaz web premium diseñada para gestionar un catálogo interactivo de películas. Este proyecto destaca por su enfoque en la estética y la experiencia de usuario (UI/UX), utilizando fondos texturizados, tipografía elegante y componentes minimalistas.

## 🚀 Tecnologías Utilizadas
* **HTML5:** Estructura semántica del proyecto.
* **CSS3:** Estilos personalizados, animaciones (hover effects) y diseño responsivo.
* **Bootstrap 5:** Framework principal para el sistema de cuadrículas, barra de navegación y pestañas dinámicas.
* **JavaScript:** Lógica de interacción del lado del cliente y manipulación del DOM.

## 💻 Características
* Barra de navegación (Navbar) transparente y completamente integrada con el fondo de mármol.
* Sistema de pestañas dinámicas para alternar entre "Iniciar Sesión" y "Registrarse".
* Botones estilo "Ghost" con transiciones suaves y acentos dorados.
* Estructura de carpetas modular (`css/`, `img/`).
* Preparación de la arquitectura base para la lógica de autenticación (en desarrollo).
